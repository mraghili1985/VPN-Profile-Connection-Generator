اگر پسورد رو اینجا وارد کنی: کلید همینجا در مرورگر رمزگشایی می‌شود و به‌صورت باز (بدون رمز) داخل فایل ذخیره می‌شود — دیگه موقع اتصال چیزی پرسیده نمی‌شود.
اگر خالی بذاری: کلید همان‌طور رمزدار داخل فایل می‌ماند و برنامه VPN موقع اولین اتصال رمز را می‌پرسد.
پشتیبانی می‌شود از: کلید رمزدار سنتی PKCS8 (هدر ENCRYPTED PRIVATE KEY، خروجی استاندارد OpenSSL 3.x) و کلید RSA قدیمی (هدر Proc-Type: 4,ENCRYPTED).

اگر یوزرنیم/پسورد را خالی بگذاری، در فایل خروجی مقدار پیش‌فرض username و password نوشته می‌شود که بعداً خودت در همون فایل‌ها (روی سرور/کلاینت لینوکسی) دستی ویرایش کن.

ℹ️ راهنمای استفاده از فایل خروجی

فایل خروجی شامل دو بخش است: بخش اول را داخل /etc/ipsec.conf و بخش دوم را داخل /etc/ipsec.secrets (روی کلاینت/سرور لینوکسی که strongSwan نصب دارد) کپی کن، سپس با دستور sudo ipsec restart و sudo ipsec up نام-اتصال وصل شو. این تنظیم فرض می‌کند گواهی سرور با یک گواهی معتبر عمومی (مثل Let's Encrypt) بالا آمده و نیازی به CA دستی ندارد؛ اگر سرورت از گواهی self-signed استفاده می‌کند، باید جداگانه گواهی CA را هم به کلاینت معرفی کنی.

⚠️ توجه: strongSwan از گواهی‌های wildcard (مثل *.example.com) برای تطبیق هویت سرور پشتیبانی نمی‌کند. Remote ID باید دقیقاً همان مقداری باشد که به‌صورت صریح در Subject Alternative Name (SAN) گواهی سرور نوشته شده (نه فقط CN و نه یک زیردامنه‌ی متفاوت با wildcard).

🍎 راهنمای نصب روی مک (macOS)

همون فایل .mobileconfig که از این صفحه دانلود می‌کنی روی مک هم مثل آیفون نصب می‌شود; دو روش برای نصبش داری:

روش ۱ (گرافیکی): روی فایل دابل‌کلیک کن تا باز شود، بعد از System Settings برو به Privacy & Security ← Profiles و روی پروفایل بزن Install.

روش ۲ (ترمینال، بدون کلیک): دکمهٔ «دانلود اسکریپت نصب برای مک» را بزن، بعد داخل Terminal بنویس:
chmod +x ~/Downloads/*-install-mac.sh && ~/Downloads/*-install-mac.sh
پنجرهٔ System Settings خودکار باز می‌شود; روی پروفایل بزن Install و رمز مک را وارد کن تا نصب تکمیل شود. (macOS از نسخهٔ Ventura به بعد، نصب خودکار از طریق خط فرمان را حذف کرده و فقط از طریق System Settings امکان‌پذیره.)
