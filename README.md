# VPN Profile Connection Generator

  <img src="logo.png" alt="VPN Profile Connection Generator logo" width="120" />
</p>

ابزار سبک و کاملاً سمت کلاینت (client-side) برای ساخت فایل‌های پروفایل اتصال VPN — بدون نیاز به سرور، بدون ارسال هیچ اطلاعاتی به بیرون، و قابل اجرا هم به‌صورت آفلاین (فایل محلی) و هم روی هاست.

## ✨ امکانات

- **L2TP/IPSec** و **IKEv2** — تولید فایل `.mobileconfig` برای iOS / macOS، با فرم واحد و ظاهری کاملاً مشابه صفحه‌ی تنظیمات VPN خود آیفون (انتخاب نوع پروتکل → پرکردن فیلدها → ساخت فایل).
- **OpenVPN** — تولید فایل `.ovpn` آماده برای اپلیکیشن‌های کلاینت OpenVPN.
- **Windows** — تولید فایل Phone Book (`.pbk`) برای اتصال VPN داخلی ویندوز.
- تمام پردازش‌ها در همان مرورگر کاربر انجام می‌شود؛ هیچ داده‌ای به هیچ سروری ارسال نمی‌شود.
- قابلیت **PWA** (نصب روی صفحه‌ی اصلی گوشی و کارکرد آفلاین) از طریق `manifest.json` و `sw.js`.

## 📁 ساختار پروژه

```
.
├── index.html      # کل رابط کاربری و منطق ساخت پروفایل‌ها (تک‌فایلی)
├── manifest.json   # مشخصات PWA (نام، آیکون، رنگ تم)
├── sw.js           # Service Worker برای کش و کارکرد آفلاین
└── logo.png        # لوگوی پروژه
```

## 🚀 استفاده

### حالت آفلاین (بدون هاست)
فقط فایل `index.html` را با مرورگر باز کنید. توجه: در این حالت قابلیت PWA/آفلاین (Service Worker) به دلیل محدودیت مرورگرها روی فایل‌های محلی (`file://`) فعال نمی‌شود؛ فقط روی HTTPS کار می‌کند.

### حالت هاست‌شده (پیشنهادی، با پشتیبانی کامل PWA)
هر سه فایل (`index.html`, `manifest.json`, `sw.js`) را در یک پوشه‌ی یکسان روی هر هاست/سرویس استاتیک (GitHub Pages، Vercel، Netlify و ...) آپلود کنید. بعد از اولین بازدید، مرورگر گزینه‌ی «Add to Home Screen» / نصب اپ را نمایش می‌دهد و ابزار حتی بدون اینترنت هم کار می‌کند.

## 🔒 حریم خصوصی

این ابزار هیچ بک‌اندی ندارد. تمام مقادیر واردشده (سرور، رمز، اکانت و ...) فقط در حافظه‌ی مرورگر شما پردازش و مستقیماً در قالب فایل پروفایل تولید می‌شوند؛ چیزی جایی ذخیره یا ارسال نمی‌شود.
